# mysteryduel

mysteryduel is a real time 2 player (for now) character guessing game.

Each player gets a secret character from a shared list of characters. Players take turns asking questions about their opponent's character and eliminate characters based on the answers.

The first player to correctly guess the opponent's character wins.

## Tech Stack

* React
* TypeScript
* FastAPI
* WebSockets
* PostgreSQL

## MVP

* 2 players
* Create / join game room
* Character selection
* Predefined questions
* Character elimination
* Turn based gameplay
* Realtime game updates
* Win / lose detection

## Future
